Set up a project in one command U10

ShippedDescribe which agent does what (planner, builder, reviewer) once, and Agent OS sets each agent up natively. Preview first; undo a whole batch later.

Milestone 3

The Brain

Plannedafter milestone 2

The headline feature: real shared memory. Designed; not built.

How we'll know it worked: ask any agent something whose answer lives in months-old work, and it answers from the Brain, citing the source.

Long-term memory

PlannedAgents remember what you know, decided and learned, not just where you left off. Ask any agent about work from months ago.
Layers
1 · who each agent is and where to look · 2 · a curated wiki of notes · 3 · a deep searchable archive · 4 · the loop that turns raw activity into clean knowledge (the real product).
Already decided
Agents write to it by default, with a source on everything and the ability to roll back; you review flagged items rather than approve everything.
Milestone 4

Team coordination

Plannedafter the Brain

Your agents act as one team instead of separate terminals.

How we'll know it worked: one real multi-agent workflow (code, research or content) planned, handed out and tracked end-to-end.
